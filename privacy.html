Kaleido Privacy

Kaleido stores the website domains and color settings you save in Chrome's local extension storage. It does not send this information or website content to a server.

When you save a theme, Kaleido asks Chrome for permission to change the appearance of that website and its subdomains. Kaleido reads visible element style information in your browser only to recolor neutral backgrounds, dark text, and borders. It does not collect page content, account information, browsing history, or analytics.

You can remove a saved theme in the Kaleido popup or remove Kaleido in Chrome to delete its local settings.

Limited Use: Kaleido uses any site access only to provide the website color theming feature the user requested. No data is sold, shared, or used for advertising.
