Kaleido Privacy

Kaleido stores saved colors, website domains where you save settings, and CSS selectors and short labels for the page areas you choose in the browser's local extension storage. It does not send this information to a server.

Kaleido asks for optional access to a website before it applies colors or lets you select areas there. It reads page structure and styles on websites where you grant access so it can find and recolor the areas you choose. It does not save full page contents, account information, or form values. A short saved area label may come from that element's title or accessible label; Kaleido does not save the page's full text. You can revoke website access in your browser's extension settings.

The optional color picker reads the selected element's CSS color to suggest a swatch. Kaleido does not collect analytics or advertising data. It reads the current tab's domain to apply site-specific settings; only domains where you save settings are retained in extension storage.

You can remove saved colors and picked areas in the Kaleido popup. The device transfer code and exported text file are compressed but not encrypted. They contain your saved colors, websites, and area selectors; anyone with either can import your settings. Both are created locally and Kaleido does not send them to a server. Website permissions remain managed separately by each browser. Removing Kaleido deletes its local settings.

Limited Use: Kaleido uses website access only to provide the coloring features the user requests, including reapplying saved colors on sites the user allows. No data is sold, shared with third parties, or used for advertising.
