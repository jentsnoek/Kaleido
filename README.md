# Kaleido

Kaleido lets you save a separate color palette for each website. The first preset is your pink/plum palette; OP.GG is prefilled when you open its page. To add another site later, visit it, open Kaleido, and save a theme for that domain.

## Install the development build

1. Extract Kaleido.zip to a folder.
2. Open chrome://extensions in Chrome.
3. Turn on Developer mode.
4. Choose Load unpacked and select the extracted Kaleido folder.
5. Visit a website, click Kaleido, adjust the colors, then choose Save theme for this site.
6. Chrome asks for access to that site's pages. Kaleido requests access only when you save that site's theme.

Saved domain names and palettes stay in Chrome local storage. Kaleido does not send page data to a server. The included privacy.html is a draft that can be adapted and hosted if you later publish in the Chrome Web Store.

The automatic recoloring targets neutral light surfaces, dark text, links, and borders. Sites with unusual layouts may need site-specific refinements.
